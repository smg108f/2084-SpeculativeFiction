# 2084 Audit & Recertification Templates

These templates define the canonical format for HPB Apotheosis Audits and Mortal Recertification Plans. Both files use the same YAML frontmatter and follow the section structure below. Do not add sections that aren't in the template; the HPB is a bureaucracy.

---

## YAML Frontmatter (both file types)

```yaml
---
source: [AI name that generated this]
status: draft
genre:
  - speculative fiction
---
```

---
